# engine

Заглушка. Здесь будет python-пакет `reels_factory` — генерализованный порт движка
`reels-saas` (озвучка ElevenLabs, аватар HeyGen v3, сценарий, нарезка видеоряда,
сборка split/fullscreen, QA-гейты). Ставится через `pip install` из
`${CLAUDE_PLUGIN_ROOT}/engine` в venv рабочей папки пользователя.
