# B-roll библиотека (Модуль B)

Клипы-подложки для семантического подбора. Модуль A пишет в сегмент
`effect.broll_query` (что показать), Модуль B (`broll_retrieval`) подбирает сюда
самый близкий по смыслу клип и проставляет `effect.src`.

Медиа-файлы и `index.json` **локальны** (в git не коммитятся) — библиотека
собирается на машине рендера.

## Наполнить

```bash
# 1a) со стоков (нужен бесплатный PEXELS_API_KEY, https://www.pexels.com/api/)
python -m reels_factory.broll_fetch --per-query 3

# 1b) или положить свои вертикальные клипы сюда вручную
#     (желательно 30fps H.264 +faststart, иначе headless-рендер не прочитает)

# 2) проиндексировать (кадры → описание → CLIP-эмбеддинг → index.json)
python -m reels_factory.broll_index
```

Цель — 30–50 клипов под нишу: рабочий стол/ноутбук, код, ИИ/нейросети,
автоматизация, заметки, командная работа, графики, телефон, абстрактный технофон.

## Описание клипов (caption + tags)

Индексатор берёт описание через `describe_fn`:

- **sidecar** (по умолчанию) — рядом с `clip.mp4` кладётся `clip.txt`:
  ```
  руки печатают на клавиатуре, заметки в блокноте
  tags: клавиатура, заметки, рабочий стол
  ```
  либо `clip.json`: `{"caption": "...", "tags": ["..."]}`.
- **VLM** (прод-путь) — `broll_index.make_llm_describer(runner)` описывает по кадрам
  через Claude.
- без описания подбор всё равно работает — по CLIP-эмбеддингу картинки; caption/tags
  нужны для читаемости индекса.

## Модель

Мультиязычный CLIP `xlm-roberta-base-ViT-B-32` (laion5b) — понимает русские
запросы напрямую, работает на CPU (тянет `torch`+`transformers`; ставится через
`pip install -e .[broll]`). Порог косинуса `0.18`, откалиброван под эту модель
(ниже → «слабый матч», фолбэк). См. `broll_library.py`, `broll_retrieval.py`,
`docs/TZ_pipeline_v6.md`.
