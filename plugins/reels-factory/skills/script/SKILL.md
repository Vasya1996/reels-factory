# Script

Инструкции ДЛЯ ТЕБЯ (Claude). Генерация черновика сценария (шаг 2 ниже) идёт
через локальный `claude -p` под капотом движка — бесплатно, платных API не
трогает. Но дальше в цикле — `/reels-factory:make` (ElevenLabs + HeyGen,
платно). **ЖЕЛЕЗНОЕ ПРАВИЛО: пока пользователь явно не сказал «ок» по
сценарию и раскадровке ниже — не запускай `/reels-factory:make` и вообще
ничего платного.**

Предусловие: `factory/hypotheses.md` заполнен (`/reels-factory:research`
пройден) и в нём есть рецепты. Если нет — останови, попроси сначала
`/reels-factory:research`.

## Шаг 1. Выбрать рецепт

Прочитай `factory/hypotheses.md` → раздел «Сводка», возьми рецепт с
наибольшим счётом. Если счета близки или у пользователя есть свежий
комментарий про то, что снимать — уточни выбор у него; не решай молча при
реальной неоднозначности.

Критерий: у тебя есть один конкретный рецепт (связка паттернов + целевая
метрика + механизм) как гипотеза для этого сценария.

## Шаг 2. Сгенерировать черновик сценария

Прочитай конфиг (`theme`/`theme_spoken`/`product`) и сформулируй по рецепту:
`hook_type` (один из fail_first/clutch_save/number_shock/question_hook/
before_after/insight_reveal — тот, что использует выбранный рецепт), `case`
(конкретный кейс, который раскрывает блогерша), опционально `insight`
(неочевидный факт).

Выбери имя рабочей папки (например `<тема-слагом>-01`, инкремент на каждый
новый рилс) и из корня рабочей папки проекта:

```powershell
$env:PYTHONUTF8="1"; .venv\Scripts\python.exe -m reels_factory script --workdir <имя> --theme "<тема>" --theme-spoken "<как звучит>" --hook-type <тип> --case "<кейс>" --insight "<инсайт, если есть>"
```

(`PYTHONUTF8=1` — иначе русская речь сценария в stdout PowerShell читается
абракадаброй; в самом файле `scenario.json` при этом всё корректно.)

Движок сам подставит `legend`/`cta_phrase`/`product_name` из
`factory/config.yaml`, прогонит валидатор (роли по порядку hook/development/
payoff/cta, хук БЕЗ упоминания продукта, тема в первых фразах, CTA —
ДОСЛОВНО `product.cta_phrase`, суммарно ≤70 слов жёстко (цель промпта — 60),
длительность 14-40с) с двумя автоматическими ретраями. Результат — JSON в
stdout и файл `work/<имя>/scenario.json`.

Если после ретраев `ok: false` — не гоняй бесконечно: упрости `case`/
`insight` (короче, конкретнее) и запусти ещё раз.

Критерий: `work/<имя>/scenario.json` существует и содержит непустые `speech`
во всех блоках.

## Шаг 3. Сверить с рецептом

Прочитай `scenario.json`. Валидатор движка проверяет только МЕХАНИКУ (роли,
лимит слов, дословность CTA и т.п.) — он НЕ проверяет, действительно ли
воплощён выбранный рецепт. Сверь сам: `hook_type` и структура кейса реально
отражают паттерны рецепта из `factory/hypotheses.md`? Если нет — поправь
входные параметры шага 2 и перегенерируй (бесплатно, не жалей попыток).

## Шаг 4. Ударения и эмоц-теги

Открой `work/<имя>/scenario.json` и вручную дополни `speech`:
- ударение-акут (U+0301 сразу после ударной гласной) в сложных/неоднозначных
  по ударению словах — чтобы TTS не ошибся;
- эмоц-теги ElevenLabs в квадратных скобках (`[смех]`, `[вздыхает]` и т.п.)
  там, где усилят подачу.

Эти правки не считаются словами при лимите. НЕ трогай саму дословную
CTA-фразу настолько, чтобы она перестала быть точной подстрокой
`product.cta_phrase` — акут внутри её слов ставить можно, слова фразы не
переставляй и не меняй.

## Шаг 5. Раскадровка

На каждый блок (`hook`/`development`/`payoff`/`cta`, и `context`, если он
есть) распиши:
- **что на экране** — для `split`: аватар сверху + что снизу; для
  `fullscreen` — только видеоряд;
- **сегмент видеоряда** — какой ролик/источник, примерный фрагмент (точный
  offset подберётся на `/reels-factory:make` по контактным листам — здесь
  ориентир, не финальное число);
- **какие паттерны** применены (ссылка на паттерн(ы) из
  `factory/analysis-<тема>.md`);
- **какую гипотезу** проверяем (рецепт из `factory/hypotheses.md`);
- **тайминги** блока (start/end из `scenario.json`; финальные тайминги
  сдвинутся после реального TTS — это черновая сетка).

Сохрани раскадровку в `work/<имя>/storyboard.md` — она понадобится на
`/reels-factory:make`.

## Шаг 6. На валидацию пользователю

Покажи пользователю реплики по блокам ПОЛНОСТЬЮ (текст, который заговорит
блогерша) и раскадровку из шага 5. Спроси явно «ок?». Правки — вноси в
`scenario.json`/перегенерируй, показывай заново. **Не переходи к
`/reels-factory:make` без явного «ок».**

## Общие правила
- Неоднозначно — переспроси пользователя ДО того, как что-то потратишь (сам
  сценарий бесплатен, но `/reels-factory:make` дальше — платный).
- Свои надписи на видеоряд НИКОГДА (в раскадровке не планируй никаких
  плашек/оверлеев — только видеоряд + караоке-сабы).
- Сабы — только речь блогерши.
- Всё на русском.

Итог этапа: `work/<имя>/scenario.json` (провалидирован пользователем) +
`work/<имя>/storyboard.md` (план broll-сегментов). Дальше —
`/reels-factory:make`.
