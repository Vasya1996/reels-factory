# Архив: консольный сценарий с непрерывным видеорядом

Эта ветка — снимок кода на 2026-07-27, **до** удаления из основного продукта.
В `main` этого больше нет. Здесь оно сохранено целиком и рабочим, чтобы можно
было вернуть, если понадобится.

## Что тут сохранено

Ручной сценарий сборки из консоли: ты сам приносишь видеофайл и сам решаешь,
в какие секунды ролика его показать.

1. Кладёшь рядом видео — кусок геймплея, стоковый ролик, что угодно.
2. Пишешь план вставок: «с 3-й по 6-ю секунду ролика показать вставку, брать её
   из этого видео начиная с 40-й секунды».
3. Запускаешь сборку, передавая и файл, и план.
4. Движок кладёт файл туда, откуда его видит сборщик, под именем `broll.mp4`.
5. Монтажный план превращает записи плана в окна: интервал, файл, смещение.
6. Revideo в эти секунды показывает твоё видео поверх аватара.

Отдельно тем же механизмом жили форматы `split` и `fullscreen` — аватар поверх
непрерывного фонового видео на весь ролик.

## Из чего оно состоит

| Файл | Роль |
|---|---|
| `engine/src/reels_factory/ingest.py` | подтянуть источник: ссылка (yt-dlp) или локальный файл, отдать путь и длительность |
| `engine/tests/test_ingest.py` | тесты к нему; один качает реальное видео с YouTube |
| `engine/src/reels_factory/pipeline.py` | ветка `if broll_source:` в `run_make` и передача пути дальше в сборку |
| `engine/src/reels_factory/__main__.py` | флаги `--broll` и `--offset` команды `make` и проверка «нужен --broll» для не-avatar форматов |
| `skills/make/SKILL.md` | описание ручного сценария целиком |

Смежное, но **не** удалённое из `main` и живущее там дальше: `editplan.py`
(ветка `source: "external"`, срабатывает только при переданном плане),
`revideo_render.py` (копирование файла для сборщика), `engine/revideo/src/project.tsx`
(отрисовка окна `broll`). Они принадлежат другому разработчику и без переданного
плана не активируются.

## Почему убрали

Бот этим не пользуется: он не передаёт ни файл, ни план — ни одного упоминания
в его коде. Живой конфиг на сервере — `format: avatar`. Вставки в продукте берутся
из другого механизма: локальной библиотеки клипов с автоподбором под смысл фразы.
То есть код рабочий, но в продукте не вызывается ни разу.

Отдельно мешал тест, качавший видео с YouTube: с серверного IP ютуб требует
подтверждения «я не бот», и прогон тестов на сервере всегда падал.

## Как вернуть

Ветка не удаляется. Взять отсюда нужные куски и перенести в актуальный `main`:

```bash
git checkout archive/console-broll-workflow -- plugins/reels-factory/engine/src/reels_factory/ingest.py
```

Дальше вернуть ветку `if broll_source:` в `run_make` и флаги в `__main__.py` —
их проще посмотреть здесь и переписать под текущий код, чем откатывать коммит:
`main` с тех пор ушёл вперёд.

Если возвращаешь — учти, что тест с YouTube лучше сразу пометить сетевым, иначе
он снова будет валить прогон на сервере.
