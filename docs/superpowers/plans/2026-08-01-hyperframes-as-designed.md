# Работать по HyperFrames так, как он задуман — план

> **Для исполнителя-агента:** ОБЯЗАТЕЛЬНЫЙ САБ-СКИЛЛ: superpowers:subagent-driven-development или superpowers:executing-plans. Шаги помечены чекбоксами.

**Цель:** перевести производство рилсов на штатный путь фреймворка — вход через роутер, автономный режим через поля брифа, неинтерактивные команды, наши шрифты в их стилях, пресет вместо перебора каталога.

**Почему план вообще нужен.** Пилот и автономный прогон показали одно и то же: мы входили в жанровый скилл напрямую, минуя роутер. Роутер — единственное место, где лежит таблица доменов (правила движения, каталог приёмов, реестр блоков, медиа-слой). Жанровый скилл нашего типа — `talking-head-recut` — на эти домены не ссылается вовсе и не содержит ни одного скрипта. Поэтому и я, и автономный агент сочиняли то, что уже написано.

**Стек:** Python 3.11 (движок), Node ≥ 20 (`npx hyperframes`), pytest, ffmpeg, headless-агент через `hf_agent.py`.

## Глобальные ограничения

- Версия CLI закреплена `0.7.70` (`hyperframes_blocks.py:25`, `hf_render.py:59`). Перед первой командой, влияющей на рендер, выполнять пробу `npx hyperframes@latest upgrade --project . --check` — она только читает и сообщает отставание. Решение об обновлении принимает Вася.
- HeyGen через их командную строку не подключаем: голос у нас ElevenLabs (`master_audio.py`), аватар — своим ключом (`avatar.py`). Строго обязательны для медиа-слоя только `ffmpeg` и `ffprobe`.
- Автономный режим выводится из полей брифа `flow: automation` + `storyboard: no`, а не из слов в запросе (`hyperframes-core/references/brief-contract.md:23-27`).
- `BRIEF.md` создаёт сам рабочий процесс на шаге настройки, после `init`; подкладывать его заранее нельзя — `init` отказывает в непустой папке (`brief-format.md:34`).
- Проверки качества (`lint`, `check`) блокируют в любом режиме (`brief-contract.md:41-49`) — не обходить флагами.
- Ветка `feat/vasya-<задача>`, push и PR только после «ок» от Васи.
- Тесты движка: `python -m pytest` из `plugins/reels-factory/engine`; полный набор идёт около трёх минут, точечные — секунды.

### Задача 2: пресет клиента — один перебор вместо ста тридцати восьми

Каталог содержит 113 блоков и 25 компонентов, из них вертикальных три. Перебирать их в каждом ролике бессмысленно и дорого. Перебираем один раз, результат кладём в пресет.

**Файлы:**
- Создать: `presets/base/preset.json`
- Создать: `plugins/reels-factory/engine/tests/test_hf_preset.py`

**Интерфейсы:**
- Отдаёт: `load_preset(name) -> dict` с ключами `styles`, `layouts`, `blocks`, `motion`, `transitions`, `media_library`.
- Потребители: `hf_brief.py` (передаёт агенту), задача 4.

- [ ] **Шаг 1: получить машинный список каталога**

```bash
npx --yes hyperframes@0.7.70 catalog --json > catalog.json
```
Именно машинный список — их документация прямо говорит, что для агентских сценариев используется `--json` и затем явная установка по имени, а не интерактивный выбор.

- [ ] **Шаг 2: отобрать пригодное**

Отбор ведёт агент, потому что нужен осмотр: поставить кандидата, снять кадр, увидеть. Критерии отбора: вертикаль 1080×1920 или размеронезависимость, отсутствие зашитой латиницы, отсутствие внешних шрифтов. Каждое решение — с одной строкой обоснования.

- [ ] **Шаг 3: записать пресет**

```json
{
  "styles": ["style-cyrillic"],
  "layouts": ["overlay", "pip", "stack"],
  "blocks": [],
  "motion": [],
  "transitions": ["crossfade", "blur-crossfade", "push-slide", "zoom-through", "squeeze"],
  "media_library": "presets/base/media/"
}
```
Переходы взяты из их реестра целиком — там ровно пять, и их скрипт понимает только эти имена.

- [ ] **Шаг 4: тест на согласованность**

```python
def test_preset_transitions_match_their_registry():
    """Имена переходов совпадают с реестром скилла — иначе их скрипт не поймёт."""
    import json, pathlib
    reg = json.loads(pathlib.Path(
        r"C:\Users\123\.claude\skills\product-launch-video\scripts\lib\transitions.json"
    ).read_text(encoding="utf-8"))
    theirs = set(reg["transitions"]) if isinstance(reg["transitions"], dict) else {
        t["name"] for t in reg["transitions"]}
    ours = set(load_preset("base")["transitions"])
    assert ours <= theirs, f"неизвестные их скрипту переходы: {ours - theirs}"
```

- [ ] **Шаг 5: прогнать тест и закоммитить**

```bash
cd plugins/reels-factory/engine && python -m pytest tests/test_hf_preset.py -q
```
