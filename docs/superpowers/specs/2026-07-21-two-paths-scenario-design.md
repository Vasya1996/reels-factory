# Дизайн: два пути сценария + хуманизация (зона Васи)

Дата: 2026-07-21. Статус: на ревью у Васи.

## Зачем

Две продажи, два типа клиентов:
- **Серик** — «вот мой текст, скажи его за меня». Текст его, менять нельзя.
- **Жанна** — «вот сырьё (транскрибация встречи), сама придумай и напиши». Текст пишем мы.

Общая цель: связный сценарий + человечная устная подача, на русском и казахском.

## Граница зон

Выход Васи = `scenario.json` (текст с разбивкой по блокам) + аудио ElevenLabs
(файлы или ссылки). Всё дальше (аватар, перебивки, монтаж, субтитры) — зона Юли.
Юля сама решает, как делать перебивки; якоря «где о чём говорит» ей не передаём.
`ingest.py`, `compose.py`, `render.py`, `captions.py` не трогаем.

## Путь 1 — «Дословно» (Серик)

1. Вход: готовый текст или голосовое (расшифровка локальным Whisper, бесплатно).
2. Правок смысла — ноль. Единственная операция: **узкий режим хуманизатора** —
   LLM-проход, которому разрешена только фонетическая запись терминов, брендов
   и иностранных слов («Microsoft» → «Майкрософт», «UGC» → «ю-джи-си»).
   Всё остальное трогать запрещено. Список замен показывается пользователю.
3. Никакого CTA от движка — ни слова сверх текста пользователя.
4. Проверок длины нет (длинные рилсы тоже залетают). В чат — информационная
   строка «~N слов ≈ M сек, озвучка+аватар ≈ $X» (прайс по актуальной модели
   HeyGen, которую подтвердит Юля). Строка живёт только в чате: в сценарий и в
   ElevenLabs не попадает.
5. Разбивка по блокам — только как формат передачи Юле: границы кусков,
   текст не меняется ни на букву.
6. «Ок» пользователя (для казахского — «ок» самого носителя, т.е. Серика)
   ДО первого платного шага. Потом озвучка ElevenLabs → передача Юле.

## Путь 2 — «Из сырья» (Жанна)

1. Вход: текст или аудио (аудио расшифровываем локально).
2. Клод в чате достаёт 2–3 идеи с обоснованием «почему зайдёт»; к каждой
   предлагает длину («панч на 30 сек» / «история на 1.5 мин»). Любое слово
   пользователя («короче», «сделай минуту») переопределяет предложение.
3. Пользователь выбирает идею → движок одной командой:
   - **генерация** первого варианта (инструкция №1 ниже; в промпте — цитаты из
     сырья для опоры на факты пользователя, язык, длина);
   - **хуманизатор** (инструкция №2 + справочник №3): переписывание под живую
     устную речь + самоаудит;
   - **судья** (рубрика №4): годен / не годен + конкретные претензии;
     не годен → автоповтор: редактор получает текст и претензии, до 2 кругов;
   - **проверка целостности**: файл создался, в каждом блоке непустой текст,
     блоки по порядку, CTA-фраза вошла дословно. Механика, не качество.
4. CTA в этом пути включён по умолчанию: фразу пользователь задаёт словами в
   диалоге настройки (setup), Клод сам записывает её в конфиг — пользователь
   ни в какие файлы не лазит.
5. Показ реплик → «ок» → озвучка → передача Юле.

## Хуманизатор: почему шаг движка, а не чат-скилл

По содержанию это тот же скилл, что нашла Юля (`humanise-text`): инструкция +
справочник + самоаудит. Отличия:
- запускает его код движка через локальный `claude -p` — шаг гарантирован,
  не зависит от памяти Клода в сессии;
- словарь свой: устная русская/казахская речь, а не английское письмо.
  Структуру (справочник + самоаудит) берём из `humanise-text`/blader-humanizer.

Справочник и рубрика — файлы плагина. Поддерживаем их мы как авторы продукта;
пользователь о них не знает и ничего не ведёт.

Готовые сервисы-хуманизаторы (Undetectable, WriteHuman, StealthWriter и т.п.)
не подходят: платные, англоязычные, решают задачу обхода ИИ-детекторов, а не
качества устной речи.

## Валидатор

Старый набор правил (длительность 14–40с, тема в первых фразах, хук без
бренда и т.д.) упраздняется как гейт. Остаётся:
- целостность (см. выше) — в обоих путях;
- дословный CTA — только в пути 2;
- всё качество — рубрика судьи.
Попутно чинится баг: валидатор валит сценарий при латинском названии темы
(`scenario.py:258`).

## Языки

Язык (`ru`/`kk`) задаётся один раз при настройке и прошивается насквозь:
генерация, хуманизатор, рубрика судьи, расшифровка аудио, озвучка. Не остаётся
мест, где текст молча становится русским (сейчас `ru` захардкожен в
`compose.py` и `transcribe.py` — второе моё, первое Юлино).

## Черновики файлов-инструкций (на ревью)

### №1. Инструкция генерации первого варианта (путь 2)

```
Ты пишешь текст короткого вертикального ролика, который человек произнесёт
вслух на камеру. Язык: {язык}. Целевая длительность: {N} секунд
(~{N*2.5} слов).

Вход:
- Идея ролика: {идея}
- Цитаты из материалов пользователя: {цитаты}
- Фраза призыва (CTA): {фраза}
- Кто говорит: {персона}

Правила:
1. Первая фраза должна удержать зрителя в первые 3 секунды. Без приветствий,
   без «в этом видео я расскажу» — сразу в суть.
2. Весь ролик — ОДНА мысль. Если хочется второй — она пойдёт в другой ролик.
3. Опирайся только на факты из цитат пользователя. Ничего не выдумывай:
   ни цифр, ни кейсов, ни результатов.
4. Разговорная устная речь: короткие фразы, как будто рассказываешь знакомому.
5. Заверши дословной фразой призыва: «{фраза}». Если фраза не задана —
   пункт пропусти, ничего не придумывай вместо неё.
6. Структура ответа: блоки текста по смысловым кускам (зацепка → раскрытие →
   вывод → призыв), в каждом блоке поле speech.
```

### №2. Инструкция хуманизатора

```
Перед тобой текст, который человек произнесёт вслух на камеру. Язык: {язык}.
Перепиши его под живую устную речь по правилам справочника (приложен ниже).
Смысл, факты и порядок мыслей менять запрещено.

Режим «полировка» (путь 2): переписывай формулировки свободно, факты — нет.
Режим «только фонетика» (путь 1): единственная разрешённая операция — записать
термины, бренды, фамилии и иностранные слова фонетически. Больше не меняй
НИЧЕГО: ни слова, ни порядок, ни знаки. Верни список сделанных замен.

После переписывания проверь сам себя по справочнику пункт за пунктом: найди
свои нарушения, исправь и только потом отдавай результат.
```

### №3. Справочник устной речи (приложение к №2)

```
КАК ГОВОРИТ ЖИВОЙ ЧЕЛОВЕК
1. Короткие фразы: до ~12 слов. Одна фраза — одна мысль.
2. Никаких сложносочинённых и причастных/деепричастных оборотов
   («осуществив внедрение, компания...» → «мы внедрили — и...»).
3. Термины, бренды, фамилии, иностранные слова — фонетически:
   «Майкрософт», «ю-джи-си», «эйч-ар». Латиницы в тексте быть не должно.
4. Избегай слов, где рядом много губных согласных (п-б-м) и труднопроизносимых
   стыков — их сложно выговорить.
5. В сложных словах ставь ударение акутом (символ ́ после ударной гласной).
6. Где уместно — эмоц-теги ElevenLabs: [смех], [вздыхает].

ЗАПРЕЩЁННЫЕ ИИ-ОБОРОТЫ (заметил у себя — переформулируй)
«давайте разберёмся», «в современном мире», «не секрет, что»,
«стоит отметить», «важно понимать», «итак,», «более того»,
«является», «данный», «осуществлять», «представляет собой»,
«в данном видео», «как мы видим», «подводя итог».
Конструкция «Это не X, а Y» — не чаще одного раза на ролик.

ПРИМЕРЫ
Плохо: «Внедрение данной системы позволило осуществить рост конверсии.»
Хорошо: «Поставили систему — конверсия выросла.»
Плохо: «Важно понимать, что контент является ключевым инструментом.»
Хорошо: «Без контента сегодня никуда.»
```

Список пополняем мы (авторы плагина) по мере находок — правкой этого файла.

### №4. Рубрика судьи

```
Перед тобой текст ролика, который человек произнесёт вслух. Язык: {язык}.
Оцени по пунктам, отвечай строго JSON:
{"pass": true/false, "issues": [{"где": ..., "что": ..., "как исправить": ...}]}

1. ЗАЦЕПКА: первая фраза удерживает внимание в первые 3 секунды?
   (Нет приветствий, нет «в этом видео», нет разгона издалека.)
2. ОДНА МЫСЛЬ: ролик можно пересказать одним предложением?
3. УСТНОСТЬ: каждую фразу можно произнести на одном дыхании, не запнувшись?
   Нет канцелярита, нет латиницы, бренды записаны фонетически?
4. СМЫСЛ: факты не искажены относительно входа, ничего не выдумано?
5. CTA: финальная фраза призыва присутствует дословно? (если требуется)
6. ЯЗЫК: весь текст на заданном языке, без вкраплений другого?

Будь придирчив: твоя задача — найти фразы, которые живой человек вслух
никогда не скажет. Сомневаешься — брак.
```

## Порядок работ

1. Путь 1 «Дословно» целиком (Серик заплатил и ждёт; не зависит от остального).
2. Хуманизатор + судья + справочник/рубрика.
3. Путь 2 «Из сырья» (реальная проверка на транскрибации Жанны).
4. Казахский насквозь.

Каждый шаг: автотесты (`pytest`, LLM подменяется заглушками), ветка
`feat/vasya-...`, показ диффа простыми словами, PR только после «ок».

## Решения, принятые в обсуждении 2026-07-21

- Текст Серика свят; исключение — фонетика через узкий режим хуманизатора.
- Проверок длины нет нигде; стоимость — информационная строка в чате.
- Идеи из сырья: список 2–3 с обоснованием → выбор пользователя → сценарий.
- Длина ролика — свойство идеи, предлагается Клодом, переопределяется словами.
- Хуманизатор — гарантированный шаг движка, не ручной проход в чате.
- Качество проверяет LLM-судья по рубрике; код проверяет только целостность.
- CTA: по умолчанию только в пути 2; задаётся диалогом настройки, не файлом.
- Пользователь не редактирует никакие файлы и справочники.
