# STATUS — ветка `feat/avatar-v-quality`

Рабочий статус форка для координации между участниками. Только техническая часть.

## Зачем эта ветка
Поднять качество аватара (переход Avatar III → Avatar V / Digital Twin) и снять привязку движка к русскому языку.

## Кто за какие модули (чтобы не конфликтовать)
| Участник | Модули | Зона |
|---|---|---|
| **Вася** | `scenario.py`, `llm.py`, `ingest.py`, скилл `script` | текст сценария |
| **Юля** | `avatar.py`, `tts.py`, `captions.py`, `compose.py`, `render.py`, скилл `make` | аватар, голос, монтаж |
| общие (предупреждать друг друга) | `pipeline.py`, `config.py`, `verify.py` | оркестрация и гейты |

Путь движка: `plugins/reels-factory/engine/src/reels_factory/`.

## Технические блокеры
1. **Язык захардкожен `ru`.** `compose.py` вызывает распознавание с `language="ru"`, в конфиге `language: ru`. Нужен сквозной параметр языка через `scenario` → `tts` → `transcribe` → `compose`.
2. **Регэксп слов только кириллица+латиница** (`scenario.py`, `_WORD_RE`). Для тюркских языков ломается подсчёт слов и определение темы: добавить недостающие буквы.
3. **Распознавание для субтитров** на не-русских языках слабое, вероятно нужен профильный файнтюн модели.
4. **Клонирование голоса** на не-русских: брать Instant Voice Clone, а не PVC.

## Статус кода
- Ветка `feat/avatar-v-quality`, в `main` НЕ влито.
- Вживую не прогонялось: нет `HEYGEN_API_KEY`.
- Решение по движку аватара: Avatar V (Digital Twin), референс-видео вместо фото (на фото закрытый рот → артефакты зубов).
- Важно для пайплайна: голос приходит извне, поэтому в HeyGen передаём `audio_url`/`audio_asset_id`, а НЕ `voice_id`+`script`.

## Текущие задачи
**Вася (текст сценария):**
1. Расширить `validate_scenario` измеримыми правилами (реплика ≤14 слов, хук ≤12, `hook_type` из списка, запрет приветствий/экспозиции в хуке, непустой `title`).
2. Режим «свой готовый текст»: разложить присланный текст по блокам без переписывания.
3. Приём текстового сырья (транскрибации) → извлечение одной идеи → сценарий.
4. Встроить шаг очеловечивания текста после генерации + повторная валидация.
5. Язык в промпт + правка `_WORD_RE`.
6. Усилить промпт хука и призыва к действию (few-shot примеры).

**Юля (аватар/голос/монтаж):**
1. Перевод `avatar.py` на Avatar V.
2. Голос: клон, поддержка не-русского.
3. Субтитры: язык + стиль по бест-практис.
4. Свуши/переходы, смещение A-ролла (джамп-каты, убрать паузы).
5. Подбор б-roll и вставок.

## Экономический ориентир для инженерных решений
Тарификация генерации аватара **посекундная**, поэтому длина ролика линейно превращается в деньги. Лимит длительности в валидаторе (сейчас 14-40 с) это не косметика, а защита себестоимости. Не увеличивать без причины.

## Порядок
Сначала разблокировать язык (без него часть клиентов не обслуживается), потом качество.
