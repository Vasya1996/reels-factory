## Задача 1. Починить превью-плеер (замечания Юлии)

1. **Нет звука**: master audio обязан играть синхронно с таймлайном.
   Проверить, что preview.html на каждом тике вызывает
   `__setMediaTime(t, playing)` iframe-а; звук стартует по кнопке Play
   (autoplay-policy), при перемотке — `currentTime` подтягивается.
2. **Аватар местами не двигается**: `.avatar-video` должен играть во всех
   сценах, где его клип видим. Проверить видимость через display клипа,
   `muted playsinline`, и что видео сикается на ГЛОБАЛЬНОЕ время ролика
   (непрерывный дубль), а не на локальное время сцены.
3. **Монтаж опережает сценарий**: сверить word-timings со звуком — взять
   5 контрольных слов по ролику, послушать/посмотреть, совпадает ли
   `start` слова с речью (допуск ±0.15с). Если сдвиг систематический —
   applied offset; если границы сцен неверны — поправить
   word_start/word_end и start/end сцен.

## Задача 2. Применить правки edit_plan.json (ревью Клода 2026-08-03)

1. `s05`: statNumber «МНОГОЕ» → **complexityCloud** (слова-стикеры вокруг
   аватара, лицо остаётся в кадре). statNumber с текстом сломает вёрстку.
2. `s06`: avatarBubble → **phoneCase** (переписка «ответы клиентам»).
   Если в compiler/blocks.mjs нет шаблона phoneCase — добавить по образцу
   blocks/g10-phone-case/index.html (декларативные data-anim/data-at).
3. statNumber остаётся максимум дважды и только с цифрами: s03 («1») и
   s08 («0 ₽») — ок.
4. `s07`: headline «БЫЛ / СТАЛ» → `null` (блок beforeAfter сам показывает
   контраст; текущий заголовок — дубль механики с грам. ошибкой).
5. **emphasis_words: ровно 1 слово в каждой сцене** (выбрать из речи сцены,
   самое смысловое) — иначе mint-хайлайт не появляется за весь ролик.
6. Переходы: добавить в сцены `transition_in`: `hard_cut` везде,
   `white_flash` для s02 (появление решения) и s09 (финал).
   Если компилятор переходы пока не рендерит — поле всё равно заполнить
   (для валидатора и будущей поддержки).

## Задача 3. Валидатор плана — compiler/validate-plan.mjs

`node compiler/validate-plan.mjs project-skills/edit_plan.json` → PASS/FAIL
со списком нарушений. Проверки (из NEXT-SESSION.md):

- avatar-first: лицо ≥50% хронометража; отрезки без лица ≤4с и не подряд;
- разнообразие: один блок ≤2 раз за ролик, соседние сцены — разные блоки;
- дубль: >60% слов headline/labels в speech сцены = FAIL
  (исключение: одиночный термин/цифра/имя);
- emphasis_words: ровно 1 на сцену;
- content-fit: statNumber label = цифра/≤4 символов; лимиты длины текстов
  по блокам (labels ≤ 3 шт, ≤ 28 символов каждый);
- переходы: primary ≥60% смен, акценты только на poворотах (≤2 на ролик).

Правленный план из Задачи 2 обязан проходить PASS.

## Задача 5. Сборка и выдача результата

1. `node compiler/compile.mjs` → build/.
2. Прогнать чек-лист приёмки (ниже).
3. **Отдать видео**: поставить HyperFrames CLI локально
   (`npm i` в POC-папке) и сделать `npx hyperframes lint` → `check` →
   `render` → MP4 1080×1920. Если CLI локально не заведётся — fallback:
   записать превью в MP4 (playwright/puppeteer screencast с звуком или
   ffmpeg-запись), явно пометив «черновая запись превью, не рендер».
4. Отдать Юлии: MP4 + ссылку на живое превью + вывод валидатора.
