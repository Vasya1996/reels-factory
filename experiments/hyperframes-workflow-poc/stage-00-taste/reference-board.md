## Приёмы SRC-A (output.mp4, editorial-язык)

### A1. editorial_card_reveal
Белая карточка с тонкой линией-шапкой наезжает на нижнюю половину кадра, крупный
чёрный заголовок собирается построчно, ключевое слово красным («СВОДЯТСЯ К ТРЁМ
ВОПРОСАМ»). Ведущая остаётся видимой сверху.
Тайминг: карточка ~0,3 с, строки по слогу озвучки.

### A2. strike_through_list
Строки списка появляются по одной и зачёркиваются красной линией по мере
произнесения («хитрые приёмы / скрипты / волшебные фразы»). Отказ = движение.
Тайминг: зачёркивание ~0,2 с, синхронно со словом.

### A3. numbered_chapter_panel
Крупный красный номер (01/02/03) + заголовок вопроса, аватар уходит в рамку
сбоку/сверху, под заголовком мелкие пункты появляются по одному
(«кто этот человек / чем живёт / какая у него боль»). Пункты гаснут в серый
перед сменой главы.

### A4. framed_avatar_shrink
Аватар из fullscreen сжимается в рамку с красной обводкой и паркуется в углу
композиции: смысловая графика забирает кадр, лицо не исчезает.

### A5. accumulate_payoff_list
Финальная сборка: СНАЧАЛА → 01 КТО → 02 ЧТО → 03 КАК накапливаются на одной
карточке, затем красная плашка CTA «СОХРАНИ ЭТО ВИДЕО» + «ПРЯМО СЕГОДНЯ».
Каждый пункт вспыхивает серым → чёрным при произнесении.

### A6. red_tag_watermark
Малая красная плашка-тег вверху кадра (номер главы/тема) — постоянный элемент
языка, меняется по главам.

## Первичный taste profile (гипотеза — подтвердить свайпом)

Что объединяет «нравится»:

- Editorial-журнальный язык: белый/кремовый + чёрная типографика + один красный
  акцент (+жёлтый вторичный). Не «неоновый тикток».
- Текст двигается по смыслу озвучки (слово произнесено → элемент появился),
  а не по таймеру.
- Отказ/негация визуализируется движением (зачёркивание), утверждение —
  накоплением (accumulate).
- Лицо почти всегда в кадре, но умеет сжиматься в рамку/вырез, отдавая кадр
  графике.
- Один основной переход (hard cut), эффектные переходы только на смысловых
  поворотах.
- Динамика достигается плотностью смысловых событий (каждые 1,5–3 с что-то
  происходит), а не мельтешением камеры.
- Юмор/лёгкость допустимы как точечная кульминация (C7), не как стиль.

Дополнение из SRC-D: динамика без движения камеры — аргументы накапливаются
(карточки-ценники), акценты «продуктовые» (selection, PiP над скринкастом),
CTA-слово совпадает с тем, что зритель должен написать в комментарии.
