## Графический язык (обязательные признаки каждого блока)

1. **Бумага в клетку** — фон всегда `paper` + сетка 67px.
2. **Рамки «от руки»**: `border: 6px solid ink` + неровный border-radius
   (пары вида `255px 34px 225px 38px / 38px 225px 34px 255px`, у соседних
   элементов разные), лёгкий поворот элемента (−1.5°…+0.6°).
3. **Жёсткие офсетные тени**: карточки `8px 10px 0 rgba(27,27,24,.16)`,
   CTA `10px 12px 0 ink`. Без blur.
4. **Стикеры**: цветной прямоугольник под цифрой/словом, повёрнут на ~−1.2°.
5. **Хайлайт**: `mint` подложка за ключевым словом (box-decoration clone),
   появляется scaleX 0→1 слева.
6. **Рукописный слой**: номера пунктов и галочки — Caveat, галочка `red`.
7. **Tech-лейбл**: чёрный штрих-дэш (rotate −1.5°) + JetBrains Mono caps
   c letter-spacing .2em.

## Анимация: «word-by-word + бумажный pop»

- Текст — по словам (word-trigger из alignment; в превью стаггер 150 мс):
  translateY(12px)→0 + fade, 200–220 мс, `cubic-bezier(.22,1,.36,1)`.
- Карточки/стикеры — pop с лёгким overshoot: `cubic-bezier(.34,1.56,.64,1)`,
  300–420 мс; стикер цифры scale .7→1, карточки translateY(30px)→0 с
  сохранением своего rotate.
- Галочка — штамп: scale .4 + rotate −20°→0, overshoot, после слов пункта.
- Хайлайт — scaleX 0→1 от левого края, 300 мс, после появления слова.
- Зачёркивание — red линия scaleX 0→1, 260 мс.
- Запрещено: blur при появлении, глитч, частицы, slam-встряски.

## Формы

- Кнопки/CTA: red фон, ink рамка 6px, неровный radius, rotate ~−1°,
  тень `10px 12px 0 ink`, текст card, Montserrat 900 caps.
- Пилюли-пункты: card фон, ink рамка 6px, неровный radius, чередующийся
  rotate ±0.4–0.7°.
- Никаких «чистых» скруглений и тонких рамок из v1.

## Акцент ключевого слова

Mint-хайлайт (из дизайна). Underline red — вторичный вариант для случаев,
когда хайлайт перегружает кадр.
