# Фабрика рилсов

*Версия 0.2 — добавлены формат `avatar` (фуллскрин-аватар с вставками
видеоряда) и настраиваемый персонаж-ведущий с опциональным клоном голоса.*

Плагин Claude Code, который превращает Claude в вашего AI-блогера: озвучивает
сценарии вашим голосом на аватаре, подкладывает видеоряд по теме и ведёт полный
продуктовый цикл выпуска вертикальных рилсов —

**анализ залетевших роликов по теме → гипотезы → сценарий на вашу проверку →
сборка рилса → метрики → playbook** — пока рилсы не начинают залетать стабильно.

Никакого готового контента и шаблонов «на отвяжись»: под тему, нишу, продукт и
голос настраиваетесь вы сами, а Claude на каждом шаге объясняет, почему выбран
именно этот приём.

## Что получаете

- Персональный AI-аватар (HeyGen) и голос (ElevenLabs) — говорит сценарий, а не
  читает по бумажке.
- Видеоряд под тему, подобранный и нарезанный под сценарий.
- Продуктовый цикл, а не разовая генерация: каждый рилс проверяет гипотезу,
  каждый результат уточняет следующий сценарий.
- Разметку сценария на согласование ДО сборки — ничего не рендерится вслепую.
- QA-гейты на выходе: длительность, разрешение 1080×1920, громкость, субтитры,
  слышимость голоса, правда по кадрам.

## Требования

- Windows
- Python 3.11+
- ffmpeg (в PATH или через `winget install Gyan.FFmpeg`)
- Claude Code
- Свои ключи **HeyGen** и **ElevenLabs** (см. FAQ по стоимости ниже)

## Установка

Две команды в Claude Code:

```
/plugin marketplace add Vasya1996/reels-factory
/plugin install reels-factory@reels-factory-market
```

## Первый запуск

```
/reels-factory:setup
```

Мастер настройки спросит: формат ролика (см. ниже), python/ffmpeg (проверит
сам), ключи HeyGen и ElevenLabs, фото для аватара, голос из списка ElevenLabs
(русские голоса) или клон вашего голоса, персонажа-ведущего, тему/нишу рилсов
и продукт (имя, легенда, CTA-фраза). Рабочая папка — та, где вы открыли Claude
Code для этого проекта (текущая папка сессии), отдельно создавать её не нужно.
Всё сохранится в `factory/config.yaml` этой папки.

### Три формата ролика

- **split** — аватар-ведущий (HeyGen) сверху + видеоряд снизу; фото
  горизонтальное. Дороже: HeyGen рендерит аватар на каждый блок.
- **fullscreen** — видеоряд на весь кадр, голос ведущего за кадром; HeyGen и
  фото не нужны — вдвое дешевле.
- **avatar** — аватар-ведущий (HeyGen) на весь кадр; фото вертикальное.
  Видеоряд опционален: отдельные вставки поверх аватара (показать кейс/пруф),
  либо вовсе без видеоряда.

После этого продуктовый цикл ведёте командами:

```
/reels-factory:research   # разведка темы, гипотезы
/reels-factory:script     # сценарий на вашу проверку
/reels-factory:make       # сборка рилса, QA-гейты
/reels-factory:review     # метрики, вердикт, playbook
```

## FAQ: сколько это стоит

**Есть ли подписка или скрытые платежи?** Нет. Плагин бесплатный, вы платите
только за свои API-ключи HeyGen и ElevenLabs — напрямую сервисам, без наценки.

**Сколько стоит один рилс?** Ориентировочно **$1-2** за рилс на озвучку голосом
и генерацию видео аватара при обычной длине сценария (30-60 секунд). Точная
цифра зависит от тарифов HeyGen/ElevenLabs на момент использования и длины
сценария — считайте по тарифам сервисов.

**Можно ли начать без HeyGen/ElevenLabs?** Нет, аватар и голос — обязательная
часть продукта: без них не собрать говорящего AI-блогера. Ключи вводятся один
раз в `/reels-factory:setup` и остаются только у вас в конфиге проекта.

**Берёте ли вы комиссию с метрик/публикаций?** Нет, фабрика ничего никуда не
публикует и не собирает данные о вас — весь цикл идёт локально в вашей рабочей
папке.
